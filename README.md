# 하루 한 끼 · Daily Meal Journal

개인용 식단 일기를 기록하는 한국어 정적 웹앱입니다. HTML, CSS, Vanilla JavaScript로 만들었으며 외부 라이브러리, 유료 API, 계정, 데이터베이스 서버가 필요하지 않습니다.

## 실행하기

가장 간단한 사용 방법은 아래 설명대로 GitHub Pages에 배포한 뒤 웹 주소를 여는 것입니다. 설치 없이 PC와 모바일 브라우저에서 사용할 수 있습니다.

개발 중에는 VS Code의 Live Server 확장으로 `index.html`을 열 수 있습니다. Python이 이미 설치되어 있다면 저장소 폴더에서 다음 명령을 실행해도 됩니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요. 이 명령은 개발 중 파일을 제공하는 도구일 뿐이며, 배포 후에는 서버를 운영할 필요가 없습니다. 파일을 직접 더블클릭해서 열면 브라우저마다 저장소 동작이 다를 수 있으므로 GitHub Pages 또는 위 방법을 권장합니다.

## GitHub Pages 배포하기

1. 이 저장소에 `index.html`, `style.css`, `app.js` 파일을 업로드하거나 커밋 후 푸시합니다.
2. GitHub 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
5. 배포가 완료되면 Pages 화면에 표시된 주소를 엽니다. 보통 `https://h-yerin.github.io/daily-meal-journal/`입니다. 배포에 몇 분 걸릴 수 있습니다.

빌드 과정이나 환경 변수 설정은 필요하지 않습니다. 모든 파일 경로는 상대 경로라 GitHub Pages의 저장소 하위 주소에서도 작동합니다.

## 사용 방법

- 오늘 날짜가 처음 선택됩니다. 달력 화살표로 월을 이동하고 날짜를 눌러 기록을 확인합니다. 파란색 점은 식사 또는 한마디가 저장된 날입니다.
- 아침·점심·저녁 카드에서 **기록 추가**를 누릅니다. 음식명은 필수이며, 사진 한 장과 메모는 선택입니다. 사진 없는 기록도 저장할 수 있습니다.
- JPG, PNG, WebP 사진을 최대 15MB까지 선택할 수 있습니다. 사진은 긴 변 최대 1600px의 JPEG로 줄여 브라우저 저장 공간을 아낍니다. 원본 사진은 변경하지 않습니다.
- **기록 저장**으로 확정하며, **기록 수정**에서 메뉴·사진·메모를 수정하거나 기록 전체를 삭제합니다.
- 하루 전체 일기는 **오늘의 한마디**에 입력하고 **한마디 저장**을 누릅니다. 내용 없이 저장하면 한마디가 지워집니다.
- **하루 식단 이미지 저장**을 누르면 1080×1350px PNG 미리보기가 열립니다. **PNG 다운로드**를 눌러 저장합니다. 지원하는 모바일 브라우저에서는 **공유 / 사진에 저장**을 사용할 수 있으며, 미리보기 이미지를 길게 눌러 저장할 수도 있습니다.
- 이미지에는 날짜, 세 끼 사진·음식명·메모, 저장된 한마디가 포함됩니다. 긴 텍스트는 이미지 안에서 말줄임 처리되며 원래 기록은 유지됩니다.

## 저장과 백업

기록과 사진은 **IndexedDB**를 통해 현재 브라우저에만 저장됩니다. 새로고침 후에도 유지되지만 **다른 기기, 다른 브라우저와 자동 동기화되지 않습니다**. 방문 주소(도메인·포트)가 달라도 다른 저장소입니다. 시크릿 모드, 브라우저 데이터 삭제, 저장 공간 정리로 기록이 사라질 수 있습니다.

- **기록 내보내기**: 모든 날짜의 텍스트와 사진을 JSON 파일로 내려받습니다. 사진과 개인 메모가 들어 있으니 안전하게 보관하세요. 아직 저장하지 않은 입력은 포함되지 않습니다.
- **백업 가져오기**: 이 앱에서 내보낸 JSON을 선택합니다. 확인 후 같은 날짜의 기록은 백업 내용으로 교체하고, 백업에 없는 날짜는 그대로 유지합니다. 복원 전에 현재 기록을 먼저 내보내는 것을 권장합니다.
- 백업은 최대 150MB까지 가져올 수 있습니다. 형식이 잘못된 파일은 저장하지 않습니다. 장기간 사용하면 사진 때문에 백업이 커질 수 있습니다.
- 저장 실패 안내가 나오면 브라우저 저장 권한과 여유 공간을 확인하세요. 앱이 저장 성공을 알린 기록만 저장이 완료된 것입니다.

## 파일 구조

- `index.html`: 한국어 UI, 달력, 편집 및 이미지 미리보기 대화상자
- `style.css`: 블루 톤 다이어리 스타일과 모바일 반응형 레이아웃
- `app.js`: 달력, IndexedDB, 사진 처리, 백업·복원, Canvas 이미지 생성

## 검증

Chromium 실제 브라우저에서 사진 포함 식사 저장·삭제, 한마디 저장, 새로고침 후 데이터 유지, JSON 내보내기·복원, 잘못된 백업 거부, 달력 이동, PNG 실제 크기(1080×1350), 360px 모바일 및 데스크톱 화면의 가로 넘침 여부를 검증했습니다. JavaScript 문법 검사도 통과했습니다.

iOS/Android 실제 기기의 다운로드·공유 동작은 브라우저와 OS에 따라 달라지므로 기기에서 추가 확인이 필요합니다. 로그인·클라우드 동기화·영양 분석은 제공하지 않습니다.
